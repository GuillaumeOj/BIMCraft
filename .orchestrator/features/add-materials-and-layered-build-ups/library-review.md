The standard is paywalled, so neither the values nor the table number could be verified, and several values do not match the French regulatory source. The user found a free, citable source and it was read in full:  > **Règles Th-Bât, Fascicule Matériaux**, published 2017-12-20 > https://rt-re-batiment.developpement-durable.gouv.fr/IMG/pdf/2-fascicule_materiaux.pdf  Its values are default thermal values: dry density bands, conductivity at a mean temperature of 10 °C, with moisture conventions per EN ISO 10456.  ### Required changes Set `document` to `Règles Th-Bât, Fascicule Matériaux (2017)` and `clause` to the section number in the table (apply to density, conductivity and specific heat of each entry). Each listed density is the upper bound of the relevant band. README should say so. - **Concrete block**: 1.15 comes from "béton caverneux" (1600 ≤ ρ ≤ 1800). For real masonry units Th-Bât points to its fascicule 4 (Parois opaques), which was not read. Mark as a generic default. - **Mineral wool**: the entry is generic. Rock wool (25 ≤ ρ < 40) gives 0.044 and glass wool (30 ≤ ρ < 40) gives 0.039. 0.044 is the conservative choice used here. Decision for the user: keep one conservative entry, or split into two materials (new keys). - **Softwood cladding**: 0.13 holds if 500 kg/m³ is the density at 15 % moisture (ρn ≤ 500). If it is a dry density, the band gives 0.15. README should state that 500 is interpreted as ρn. - **Wood-fibre board** has no default in this document (it refers to the RT 2012 annexes IX). Remove it rather than ship an unsourced value. Search for any reference to it in tests, docs or UI, and update them. - **Insulation**: the values above are defaults for use without a declared value. Declared product values (λD) should be able to override them. This is a design note for the user, not part of this task. - Th-Bât is dated 2017 and written for RT 2012. Ask the user to confirm it is still the current edition (RE2020 may have updated rules).  ## 4.
