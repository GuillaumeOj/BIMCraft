# Change the interface language

BIMCraft is available in English and French. By default it uses the language of your computer; you can choose another one at any time, without restarting.

## Steps

1. In the title bar at the top of the window, open the **Language** list.
2. Choose **English** or **Français**.

**Result:** every label and message switches to the chosen language at once. BIMCraft remembers your choice the next time you open it.

To go back to the language of your computer, choose **System language** in the same list.

## Options

| Option | What it does |
| --- | --- |
| System language | Uses your computer's language when it is English or French, and English otherwise. Follows changes to your computer's language. |
| English | Always shows the interface in English. |
| Français | Always shows the interface in French. |

## Troubleshooting

**Some text stays in English after choosing Français.**
That text has not been translated yet; BIMCraft shows the English wording rather than leave it blank. Please report it so it can be translated.

**BIMCraft forgets my choice when I reopen it.**
Your choice is saved by the program's web view. If your system blocks it from saving data (for example, a private or locked-down browser profile when using BIMCraft in a browser), choose the language again each time, or set your computer's language instead.
