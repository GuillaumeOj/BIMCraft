# API contract — schema and command API identifiers

Only identifiers and titles of the published JSON Schemas change. No command, query, parameter, result or error changes shape.

| Document | Field | Before | After |
| --- | --- | --- | --- |
| `schema/api/protocol.schema.json` | `$id` | `urn:bimcraft:api` | `urn:fabrilo:api` |
| `schema/api/protocol.schema.json` | `title` | `BIMCraft command API` | `Fabrilo command API` |
| `schema/core/api.schema.json` (also embedded in the protocol schema) | `$id` | `urn:bimcraft:schema:core` | `urn:fabrilo:schema:core` |
| `schema/core/api.schema.json` | `title` | ``BIMCraft `core` schema`` | ``Fabrilo `core` schema`` |
| any namespace `<ns>` generated by `schema-gen` | `$id` / `title` | `urn:bimcraft:schema:<ns>` / ``BIMCraft `<ns>` schema`` | `urn:fabrilo:schema:<ns>` / ``Fabrilo `<ns>` schema`` |

The old URNs are not accepted anywhere after the change (ADR 0028, "No compatibility").

The UI command client (`ui/src/api/`) does not read `$id` or `title`; `protocol.gen.ts` stays byte-identical.
