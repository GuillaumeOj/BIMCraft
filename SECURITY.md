# Security policy

## Reporting a vulnerability

Do not open a public issue. Report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on the repository page. Include the affected version or commit, steps to reproduce, and the impact you expect. Please do not attach confidential project models.

We acknowledge reports within 5 working days and agree a disclosure date with the reporter once a fix is available.

## Supported versions

BIMCraft has no release yet. Once releases exist, this section will list which versions receive security fixes.

## Scope

Of particular interest: crafted files (IFC, DXF, BCF, project files) that crash, hang or execute code; escapes from the plugin or MCP sandboxes (`SEC-02`); leaks of model content (`SEC-03`); and supply-chain issues in dependencies or CI.
